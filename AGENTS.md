# RenterShield Team Development Rules

We are building a Next.js, TypeScript, Supabase, and OpenAI web application for a 24-hour hackathon.

- Follow the existing application architecture.
- Reuse shared TypeScript interfaces in the `types/` directory.
- Do not change API response formats without agreement.
- Do not rewrite unrelated components or routes.
- Do not modify database migrations without coordinating with the backend developer.
- Do not install unnecessary dependencies.
- Keep API keys and sensitive logic server-side.
- Validate all incoming data.
- Preserve original inspection evidence.
- Run the project's build and relevant tests after changes.
- Report files changed and any integration steps required.
- Do not commit, push, merge, or delete branches without developer approval.
